# 表格与意见格式（公开通用口径）

本目录的 7 份母版只提供版式、公式骨架和空白占位，不含任何批次业务数据。项目特定口径（地方主管部门名称、留用地比例与取位、固定出稿句、问题抑制清单）由使用者在本机另行配置，不随公开库发布。

## 1 占位符

母版中以下方括号为待填占位，交付前必须全部替换：

| 占位 | 用途 |
|---|---|
| 【项目名称】 | 封面、正文标题、表标题、页眉 |
| 【批次】 | 段/批次全称，如“××段第×批” |
| 【补偿类别】 | 征收土地及青苗／征收土地、青苗及竹果木／征收土地及竹果木／地上构建物／坟墓迁移 |
| 【建设单位】 | 审核意见第二页与正文抬头 |
| 【送审金额】【审核金额】【核减金额】及对应“大写” | 第二页金额行，下划线内填数 |
| 【审核日期】 | 封面、第二页、末页，格式与母版一致 |
| 【文号】 | 委托或批次文号 |
| 【主管部门】 | 资料符合性核查表中“下发的汇总表”的发文单位 |

填制说明见工具文档；母版和正式表不放“填表说明”。正式成果清除剩余占位，公开空白母版保留占位。

## 2 五份表

| 文件 | 工作表 | 用途 |
|---|---|---|
| 土地_青苗竹果木.xlsx | 补偿审核汇总表、补偿审核明细表 | 土地＋留用地＋基础青苗＋竹果木 |
| 土地_青苗鱼塘.xlsx | 补偿审核汇总表、补偿审核明细表 | 土地＋留用地＋青苗／鱼塘搬迁；不含竹果木打印版块 |
| 房屋构建筑物.xlsx | 补偿审核汇总表、补偿审核明细表 | 房屋、装修、附属物、构建筑物 |
| 坟墓迁移.xlsx | 坟墓审核汇总表、坟墓审核明细表 | 按墓号逐行，按行政村汇总 |
| 资料符合性核查表.xlsx | 资料符合性核查表 | 电子件／扫描件收件与内容待核 |

土地每批交付一个补偿审核工作簿，包含“补偿审核汇总表”和“补偿审核明细表”两张表。两张表直接打印，输入位置和公式保留，明细辅助列 BL–BP 隐藏。行政村取原件村级字段，组名另存，缺村级依据列待核。其他模板按各自布局入口处理。

## 3 数据与公式

- 送审数量、单价、金额保留原件原值，不因明细与汇总不一致而改原值；差异留待说明。
- 已确认采用数量、标准及取位依据后，审核金额按本批金额精度计算（母版预设 ROUND(审核数量×审核标准, 2)）；核增减＝审核金额－送审金额。审核栏独立计算，不直接引用送审金额单元格。
- 母版金额显示两位小数（`0.00`），预设 ROUND 到 2 位；本批适用依据有其他精度时同步调整公式与显示，并在底稿记明依据。面积等其余数值保持本批所需精度。身份证、银行卡、带前导零编号按文本保存。
- 地号（墓号）为空时明细公式返回空白；地号已填但必要审核数量、标准或比例未确认时，相应审核金额及不完整合计仍保持空白。录入送审原值不等于确认审核输入，显式且已确认的0才表示零值。
- 留用地比例在土地明细表 `BN2`，母版初始为空。比例与基数依据确认后再填；公式按本次适用依据和已确认取位口径取值（依据取 4 位则 `ROUND(基数×比例,4)`，依据不取位则不取位），金额再 ROUND 到 2 位。基数不是该行合计面积时，必须改对应公式并在底稿记录依据。
- 竹果木表头写“数量”，明细与汇总直接 SUM；明细保留原计量单位，混合单位只作表式合计，不用于限额判断。
- 同地号土地与竹果木尽量同一行，行前姓名用土地补偿人；权利人不同仍另留底稿核查。土地及每笔费用只计一次。

## 4 扩行与汇总

1. 在“合计”行之前插入所需行，复制上一数据行的整行格式与公式；逐列核对相对引用是否随行号平移。
2. 同步修改：合计行的 SUM/COUNTA 范围、汇总表引用范围、打印区域、分页位置。只复制可见数值不算完成。
3. 土地明细 BO 列填行政村、BP 列填地类，均在打印区域外。汇总按行政村和地类双条件 SUMIFS 取数，交错排列也不重复整批费用；不在汇总造平均单价。扩行后运行 `python tools/land_summary.py 输入副本.xlsx --output 新副本.xlsx --detail-end-row 实际最后一条明细行 --fill-summary`，明细起行固定6，下一行为合计。工具不依 max_row 猜范围，保留已采用的人工审核数值和自定义公式；缺关键数量、标准或比例时相关审核栏与合计保持空白待核，显式零值可计算。
4. 坟墓汇总表用 `SUMIFS(明细取数列, 明细行政村列, 本行行政村)`，按行政村分别汇总；合计行再对村行求和。不得把整批合计重复到每个村。明细行政村列在最后（N 列），扩行时同步扩展 SUMIFS 范围。
5. 按本次显式类别设置打印分区并隐藏范围外的列。零金额本身不能确定类别是否在范围内。

## 5 版式与打印

- 土地审核表用 A4 横向和分页预览。汇总整张打印为一页。明细先排征地及留用地，再排青苗及鱼塘搬迁、竹果木等实际申报类别。每个分区内送审和审核左右并列，地号、姓名、表头在续页重复，人数多时纵向续页。补偿合计及备注与最后一个实际分区同页，末行合计与最后一条明细同页。
- 土地汇总表、明细表的 A1 与打印页眉采用同一个实际标题，均设为22磅加粗。正文按12磅设置，页脚仅页码。单页及分区缩放可能改变打印出来的字号，记录实测字号并目视检查清晰度。其他类别按各自 A4 打印布局设置正文、标题及缩放。
- 土地明细普通行高至少约29磅，保留已设较高的备注行。汇总隐藏零值，明细未申报分项的零值也留白显示。零值仍按原公式参与计算，待核金额保持空白。
- 扩行、删行或类别变化时，重设合计、汇总范围和分页。按实际使用的软件重算、保存后重新打开再导出。使用 WPS 交付时，在 WPS 检查汇总页数、分区左右边界、重复列及末页合计。Excel 导出仅作为 Excel 打印证据。
- 审核表默认四边10毫米。核查表默认左右5毫米、上下10毫米。按项目口径可调整边距。标题行按长标题增高，表头、备注、合计与外框边线完整，长文本换行并增高。
- 按布局清单导出 PDF，逐页检查标题、实际字号、边框、字段和分页。可辨认度、表头、合计与最后一条明细是否同页均以实际页图确认。
- 打印报告版本2绑定当前成果、PDF和逐页图片哈希；自动指标与实际看页记录均完整才通过。旧报告只作历史证据；改稿或重新保存后重新导出。具体接口见 `../docs/tools.md`。

## 6 资料符合性核查表

- 每批在各自的成果子目录交付 `征地拆迁资料符合性核查表（改）.xlsx`。一律使用这个文件名。以核定的母表复制后填制，表内标题、说明和资料名称按原表或本次已确认的批次资料填写。
- A4 纵向打印时优先把宽度给“资料名称”，电子版和扫描件两栏要容下表头和勾选。常用资料名称单行，长名称和说明自然换行，并按实际行数设置行高。
- 电子版与扫描件分栏记录：Excel 明细、汇总在电子栏；PDF 扫描的图、协议、登记、签字、照片、证件在扫描栏；两种都提供才两栏都勾。
- √ 只表示“已收到该载体”，不等于内容已核、业务合格。内容是否核对在底稿另记。
- × 只用于确认本批应提供而整批缺失的资料，且意见中要有对应一条；个别对象缺件写进意见或待核说明，不在本表打 ×。确认不适用写“/”；范围外类别整行隐藏，不删除。
- 协议内常附身份证、账户、照片等，按用户口径可暂记扫描栏，但须逐项标注“附件内容待核”，回源后更正。
- “（四）”标题固定为“【主管部门】下发的汇总表”，本批具体汇总表名称写在其下第一项。
- 标题区为“资料符合性核查表”、项目名称、补偿项目，均无边框，省去额外批次／审核日期框。项目名称取本次配置的完整名称；补偿项目含本批全称及类别。按 INITIAL / PAYMENT / SETTLEMENT 与显式类别生成可见段落；请款和结算沿用现有审核资料目录，阶段特有凭证仍按检查目录核验。
- 工作簿保护或加密标志先实际试读；能读则正常核验，确实失败时在对话询问。读取失败留内部记录，不因标志生成正式意见或审查表中的“内容未核／请提供密码”条目。

## 7 两份意见

两份独立可编辑，不能互相替代。

**初审意见.docx**：以用户最近定稿的同类初审意见为文笔和版式参照，按其标题、编号和日期出稿。土地项目可用“【项目简称】【段及批次】土地补偿初审意见”。用户已删改的意见按其确认范围保留。正文逐条写已回查的实质问题与明确补正动作；每条以“。”结束。无问题写“无。”，初审采用无金额页版式。

- 意见直接写资料名称及载体、测量地号、原值和对照值。不同资料不一致用“两者不一致，请核实”。有明确缺件用“请补充”，图件缺章用“请补盖”。仅凭图面用途无法支持全面积申报时，用“按全部面积进行青苗补偿依据不足，请核实或提供相关佐证材料”。
- 一条内涉及两种载体（扫描件、电子件）时，逐句标明各自载体，不并称、不以一处载体代表另一处。身份号码、联系电话类差异只写两处记载与“两者不一致”，不判断哪份为准。
- 页码、单元格、复算过程和正常项主要留在底稿。正文保留识别问题所需的必要原值；实际涉及补偿的差异可写清面积、数量或金额。人工样稿和第三方审阅作为线索，事实逐条回本批原件确认。

**审核意见.docx（请款）**：同类正式定稿优先。依次核封面、金额及签章页、项目基本情况、审核依据、审核意见、其他需说明事项、附表与日期。金额页大写和括号内的金额使用已有下划线样式。文件名称、封面和正文标题用本批实际补偿类别。

- **项目基本情况**。根据本次送审资料写征地面积、设施数量或迁坟穴数，列本批实际发生的补偿分项。只有本次现场记录能够证明时才写“经实地丈量及清点核实”。
- **合规性审查**。按资料名称、涉及权利人或地号、现有记载和核对结果写。缺件写“请补充完善”，明确错填写“请修正”，两处原值不一致写“请核实修正”。签字版明细、协议收款户名、所附账户证明和证件分别核对。每个问题自本小节编号。
- **补偿费用审核**。已确认送审、审核金额相同时写“送审金额为【金额】元，审核金额为【金额】元，审核无增减”。确有增减时写明调整额及原因，定位对象、对应证据和金额。已确认金额、仍需补正的支付手续分别表述。只在事项及款项已定位且补正要求有依据时写“合规性审查第【条号】条，建议补充资料后再支付对应款项”。
- **其他需说明事项及附表**。按补偿对象写发放后补交转账凭证、收款收据，以及阶段性拨付审核范围。附表依本次实际交付登记，名称与审核表文件或表头逐一核对。封面、金额页和正文金额勾稽，导出检查空白页及孤立落款。

## 8 性质与边界

母版中的公式、占位与合成示例只用于演示计算和版式，不是政策依据，也不代表任何批次已审核。政策适用、补偿标准、权属与收件结论以本次原件和适用文件为准。项目特定口径见维护者私有配置，不在本公开目录。
