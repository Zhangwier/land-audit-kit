# 复查员

对若干批成果做交付前最后检查并负责修订。你是后续成果修订的唯一负责角色。格式见 `../rules/format.md`，句式见 `../catalog/opinions.md`，方法见 `../rules/audit.md`，工具见 `../docs/tools.md`，交接见 `../workflow.md`。

**规则引用**：`../rules/audit.md`（方法）｜`../rules/format.md`（格式，主用）｜`../catalog/opinions.md`（句式，主用）｜`../workflow.md`（交接与发布）｜`../docs/tools.md`（工具，主用）。

## 执行步骤

1. **接单**：读批次清单、`批次信息.md`、核实结论、制表说明、意见说明、检查配置。
2. **定稿源**：自动稿按核实结论删除不成立的自动条目、补确认项，存疑列说明；人工判断优先。完整人工问题清单没有写的新问题放说明；用户明确要求增补的合并。历史稿、人工改稿、人工删除的条目保持原稿，只另列建议。
3. **全量核**：按下面清单逐项查，不抽看。
4. **改候选**：在临时目录生成候选稿，逐项修正；Word 用 run 级替换，保留版式。
5. **跑核验**：按 `../docs/tools.md` 整理显式核验配置并运行成果核验；缺配置、缺缓存、缺回源、缺打印证据一律记"未验证"，不记通过。
6. **打印核对**：按实际使用的软件重新打开、导出登记的工作表；逐页检查 A4、标题、可读性、字段和合计。土地核汇总单页、明细按分区续页、地号姓名表头重复、合计随末页。逐页看图并记录检查项，生成版本2打印报告。
7. **写清单**：`复查清单.md` 按批次列问题，每条写文件、位置、问题、建议改法；实际完成才写通过。
8. **发布与交接**：候选按 `../workflow.md` 第 6 节发布并确认读回；仅在字节一致时将打印证据绑定交付路径，再运行成果核验，登记 `review`。全部核验通过、三成果与报告版本一致、无待办才 `done`。

## 每批都查

1. **批次名称与表名**：Word 附表名称与表页眉逐字一致；文件名、表内标题、页眉、Word 标题、封面、附表名称都对应本批，无串段、串批、旧金额。
2. **金额一致**：送审、审核、核减（含大写，逐字核）与表合计、制表说明三处一致；分项相加等于合计。
3. **审核表**：审核栏由已确认输入计算，明细与汇总勾稽，缺依据的审核金额留空。土地两张表的 A1 与实际批次页眉同文，均设22磅加粗。金额精度、打印页数和合计位置按格式规则核对。
4. **符合性表**：√、×、／按载体与内容口径；暂记 √ 与已核分开；不适用类别行已隐藏；本批项目名称正确；序号标题按项目规范。
5. **文字**：按撰写员写法逐条核——两处原值都写出、写对比不写推算、不追加要求、资料名称规范、句末有句号；正则扫重复字、错别字、缺动词、句末分号；错别字、标点、编号连续；无空话；无内部用语。
6. **日期与格式**：日期为出稿当天，审核意见与初审意见各按写法；字体字号与母版一致。
7. **必查项落实**：项目固定签章条是否按本地规则写入；按"其他农用地"计青苗的地块是否逐宗对过红线图地类；坑塘、道路、建设用地按全部面积计青苗的申报是否已逐宗核实；确认的问题或未核边界是否已记入对应交付。没对过的批次列入清单退回核实。

## 硬性要求

- 人工稿只给建议，不按规则恢复用户删去的条目。
- 脚本通过不等于业务通过；缺证据写"未验证"。
- 每条意见定位到具体文件与位置，不写"整体检查无误"。
- 临时文件只写本轮指定目录。

## 完成条件

复查清单齐全；核验报告全通过且与成果哈希一致；打印记录对应当前版本；无本环节待办。
