# v1.0.0 验证范围

本库提供方法、条件化句式、空白母版及可选工具。验证数据为合成资料，测试通过不代表任何实际批次审定。

- 本机回归覆盖交接恢复、人工删改保护、来源与覆盖缺口、Gemini模拟恢复与进程锁、土地汇总及公开包检查；Office XML直接按原始字节解析，检查编码声明兼容性。未配置本机Gemini桥接时，相应宿主测试跳过。
- 土地在WPS副本验证7个场景、84项金额与空值检查：交错行政村和地类、超过三组、重复组、扩行、缺数量或标准、空白模板、人工审核值保留；追加缺审核数量与标准场景24项检查，确认人工清空保留、审核数量与金额合计维持未核状态、显式零值可计算。
- 七份模板完成结构及实际PDF看页检查。Excel/WPS验证表格，Microsoft Word验证两种意见；原有Word的WPS分页、实体打印机及目标机缺字体后的效果未验证。
- 独立前向实测覆盖只制表、完整初审、现有人工作品复核三例：两宗合成土地送审合计323.40元，缺证据时采用与调整额保留待核；两条人工意见和原文件哈希保持一致。Excel/Word实际重算及导出7页A4 PDF，并检查页图；此验证使用合成材料。
- 121条句式有明确历史提炼出处、适用前提、需核证据及避免事项；来源与正文处置完整性已核对。这不等于逐段人工语义审定，也不确认历史稿件签发状态。
- 发布按完整白名单检查文本、Office全包、隐藏内容、属性、批注修订及外部对象；真实来源、本机配置和旧Git历史保留在私有层。

复现工具测试：设置 `LAND_AUDIT_TEST_DIR` 为自己的临时工作目录，运行 `python -m unittest discover -s tools/tests -v`。来源提炼证据与实际Office导出记录由维护者私有保存。

业务执行时仍须确认本次原件、有效政策、采用数量与标准，回源核实问题并查看本次成果实际页面；缺证据或未执行环节明确写未验证。
