# v1.1.0 更新

土地审核表由同一工作簿的汇总、明细两张表直接打印。汇总 A4 单页，明细按补偿类别分区，补偿合计随末分区。工作表标题与页眉均设为22磅加粗，实际字号和分页由交付软件导出后核对。

- 土地费用分区内保留送审、审核左右两栏，明细续页重复地号、姓名和表头。坟墓打印视图去掉空白，土地辅助列隐藏，表格说明移入文档。
- 符合性表按阶段和类别显示，标题区无框，项目全称由本机配置提供。工作簿保护标志先实际试读，失败在对话中询问，不自动生成加密意见。
- 独立Excel／Word或WPS实例重算、保存并读回，只导出登记的打印表；避免Excel分组选中状态夹带计算表。
- 版本2打印报告解析真实PDF，验证尺寸、字号、标题、字段及逐页图片，实际看页记录完整后才通过。发布后读回，文件占用与部分交付保留待交付状态。

入口与配置见[工具说明](tools.md)。v1.0.0标签和下载包保留；台账schema、角色状态及既有运行目录保持兼容，旧打印报告需要重新导出才能满足新版验收。业务原件和人工成果只读，人工删除的意见保持删除。
